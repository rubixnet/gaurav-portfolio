# Gaurav’s World

**A walkable 3D portfolio by Gaurav Bhaturkar.**

Explore a coastal island, step inside a furnished house, and discover my projects, interests, and story through interactive spaces. Built with Next.js and Three.js, this portfolio combines web development, game development, and a love of creative exploration.

## About Me

I am a **web developer and game developer** with an interest in creating horror games. I am a first-year **Electronics and Telecommunication Engineering** student at **Shri Sant Gajanan Maharaj College of Engineering, Shegaon**.

I enjoy making creative things and exploring new ideas. Away from the keyboard, my interests include traveling, music, badminton, and cricket.

## Experience

- **Explore the island:** animated ocean, swaying trees, a garden, a badminton court, and a lighthouse.
- **Discover the house:** music studio, sports room, personal bedroom, and an upstairs creative workspace.
- **Use the computer:** browse Web Lab, read about my horror-game interests in Game Lab, and find my social profiles in Connect.
- **Enjoy the balcony:** take a seat to view floating project cards above the ocean.
- **Choose your route:** walk freely or use the map to travel between locations.
- **Adjust the atmosphere:** switch between automatic time, daylight, sunset, and night, with optional ambient sound.

The interface supports keyboard navigation, mobile touch controls, and reduced-motion preferences. On phones, the computer opens in a readable app view.

**Next.js · React · TypeScript · Three.js · React Three Fiber · Drei**

The world uses GLB models, custom shaders, and reusable 3D components, with HTML interfaces for readable content and accessible controls.

## Getting Started

Install Node.js and npm, then open the project folder in your terminal.

Install the dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Visit **[http://localhost:3000]** in your browser.

## Controls

| Action | Control |
| --- | --- |
| Walk | WASD or arrow keys |
| Run | Hold Shift |
| Move to a point | Click the ground |
| Open the map | M or the Map button |
| Interact | Enter, E, or the displayed action button |
| Open projects | P |
| Travel to a location | Number keys 1–9 or select a map destination |
| Close a panel or cancel click-to-walk | Escape |
| View instructions | Circular **?** button |

On mobile, drag the on-screen joystick to walk and tap the action buttons to interact. The settings bar controls sound, graphics quality, and time of day.
